# 课堂随机点名

给老师上课用的随机点名和分组工具。整个程序就是一个 HTML 文件，不用安装，不用联网，双击就能用。

## 怎么用

1. 下载 `课堂点名.html`，保存到电脑上。
2. 用 Chrome 或 Edge 打开（Windows、Mac 都可以）。
   不要在微信里直接预览，要先保存到电脑上再用浏览器打开。
3. 到「名单」页导入 Excel 名单，就可以开始点名了。

## 功能

- **随机点名**：名字滚动后慢慢减速，停在被点到的同学身上。可以一次点多个人；同一轮里点过的人不会重复被点。
- **随机分组**：设好组数，一键分组，结果可以复制或导出 Excel。
- **多个班级**：左上角切换班级，每个班的名单和记录分开保存。
- **今天缺席**：在点名页点一下名字标记缺席，当天点名和分组都会跳过，第二天自动恢复。
- **音效**：右上角开关，可以关掉。
- **全屏**：右上角按钮或按 F 键，适合投影。

## 名单格式

Excel 第一个工作表，第一行是表头：

| 序号 | 姓名 | 成绩 |
|---|---|---|
| 1 | 张三 | A |
| 2 | 李四 | B |

- 只有「姓名」一列也可以。
- 「成绩」填 A / B / C，用于分组时均衡搭配；没有这一列时全部按 B 处理。
- 可以在「名单」页下载模板，也可以参考仓库里的 `示例名单.xlsx`。

## 快捷键

| 按键 | 作用 |
|---|---|
| 空格 | 开始点名 / 停 / 再点一次 |
| Esc | 返回 |
| F | 全屏 |

## 数据保存

- 名单和记录保存在浏览器里，换浏览器或清除浏览器数据就会丢失。
- 建议隔一段时间在「名单」页点「导出备份」，换电脑时用「恢复备份」导回去。

## 开发

源码是 `src.html`。`课堂点名.html` 是把 Excel 读取库（[SheetJS](https://sheetjs.com/)）合进去之后生成的单文件版本：

```bash
npm install
python3 build.py
```
